## 1. Two Pointer Technique
**Description**: Uses two pointers to traverse arrays/strings in **O(n)** time.

**Use Case**: Find pairs with a sum, merge sorted arrays.

**Example**: Find Pair with Given Sum  
Find two numbers in a sorted array that add up to the target.

```javascript
function findPairWithSum(arr, target) {
    let left = 0, right = arr.length - 1;
    while (left < right) {
        const sum = arr[left] + arr[right];
        if (sum === target) return [arr[left], arr[right]];
        sum < target ? left++ : right--;
    }
    return [];
}
```

**Usage**:
```javascript
const arr = [2, 7, 11, 15];
console.log(findPairWithSum(arr, 9)); // [2, 7]
```

**Complexity**:
- **Time**: O(n)
- **Space**: O(1)

## 2. Sliding Window
**Description**: Maintains a dynamic window for contiguous subsequence problems.

**Use Case**: Longest unique substring, max sum subarray.

**Example**: Maximum Sum of Subarray of Size K  
Find the maximum sum of a contiguous subarray of size `k`.

```javascript
function maxSumSubarray(arr, k) {
    if (k > arr.length) return 0;
    let windowSum = arr.slice(0, k).reduce((sum, num) => sum + num, 0);
    let maxSum = windowSum;
    for (let i = 0; i < arr.length - k; i++) {
        windowSum = windowSum - arr[i] + arr[i + k];
        maxSum = Math.max(maxSum, windowSum);
    }
    return maxSum;
}
```

**Usage**:
```javascript
const arr = [1, 4, 2, 10, 2, 3, 1, 0, 20];
console.log(maxSumSubarray(arr, 4)); // 24
```

**Complexity**:
- **Time**: O(n)
- **Space**: O(1)

## 3. Hash Maps
**Description**: Uses `Map` or `Object` for **O(1)** lookups.

**Use Case**: Find duplicates, group anagrams.

**Example**: Find All Anagrams in a String  
Find starting indices of `p`’s anagrams in `s`.

```javascript
function findAnagrams(s, p) {
    const result = [], pCount = {}, sCount = {};
    for (let char of p) pCount[char] = (pCount[char] || 0) + 1;
    for (let i = 0; i < p.length; i++) sCount[s[i]] = (sCount[s[i]] || 0) + 1;
    if (JSON.stringify(pCount) === JSON.stringify(sCount)) result.push(0);
    for (let i = p.length; i < s.length; i++) {
        sCount[s[i - p.length]]--;
        if (sCount[s[i - p.length]] === 0) delete sCount[s[i - p.length]];
        sCount[s[i]] = (sCount[s[i]] || 0) + 1;
        if (JSON.stringify(pCount) === JSON.stringify(sCount)) result.push(i - p.length + 1);
    }
    return result;
}
```

**Usage**:
```javascript
const s = "cbaebabacd", p = "abc";
console.log(findAnagrams(s, p)); // [0, 6]
```

**Complexity**:
- **Time**: O(n)
- **Space**: O(k) (k = character set size)

## 4. Sorting Tricks
**Description**: Sorts arrays for efficient processing.

**Use Case**: Merge intervals, find kth largest element.

**Example**: Merge Intervals  
Merge overlapping intervals.

```javascript
function mergeIntervals(intervals) {
    if (!intervals.length) return [];
    intervals.sort((a, b) => a[0] - b[0]);
    const merged = [intervals[0]];
    for (let current of intervals.slice(1)) {
        if (current[0] <= merged[merged.length - 1][1]) {
            merged[merged.length - 1][1] = Math.max(merged[merged.length - 1][1], current[1]);
        } else {
            merged.push(current);
        }
    }
    return merged;
}
```

**Usage**:
```javascript
const intervals = [[1, 3], [2, 6], [8, 10], [15, 18]];
console.log(mergeIntervals(intervals)); // [[1, 6], [8, 10], [15, 18]]
```

**Complexity**:
- **Time**: O(n log n)
- **Space**: O(n)

## 5. Binary Search on Arrays
**Description**: Finds a target in a sorted array in **O(log n)** time.

**Use Case**: Search elements, find boundaries.

**Example**: Search in Rotated Sorted Array  
Find the target’s index in a rotated sorted array.

```javascript
function searchRotatedArray(nums, target) {
    let left = 0, right = nums.length - 1;
    while (left <= right) {
        const mid = Math.floor((left + right) / 2);
        if (nums[mid] === target) return mid;
        if (nums[left] <= nums[mid]) {
            if (nums[left] <= target && target < nums[mid]) right = mid - 1;
            else left = mid + 1;
        } else {
            if (nums[mid] < target && target <= nums[right]) left = mid + 1;
            else right = mid - 1;
        }
    }
    return -1;
}
```

**Usage**:
```javascript
const nums = [4, 5, 6, 7, 0, 1, 2];
console.log(searchRotatedArray(nums, 0)); // 4
```

**Complexity**:
- **Time**: O(log n)
- **Space**: O(1)

## 6. Prefix Sum
**Description**: Precomputes cumulative sums for **O(1)** range queries.

**Use Case**: Range sum queries, subarrays with given sum.

**Example**: Range Sum Query  
Compute the sum of elements in each range.

```javascript
function rangeSumQuery(nums, queries) {
    const prefix = [0];
    for (let i = 0; i < nums.length; i++) prefix[i + 1] = prefix[i] + nums[i];
    return queries.map(([left, right]) => prefix[right + 1] - prefix[left]);
}
```

**Usage**:
```javascript
const nums = [1, 2, 3, 4, 5], queries = [[1, 3], [2, 4]];
console.log(rangeSumQuery(nums, queries)); // [9, 12]
```

**Complexity**:
- **Time**: O(n) preprocessing, O(1) per query
- **Space**: O(n)

## 7. In-place Modification
**Description**: Modifies arrays directly to save space.

**Use Case**: Reverse arrays, remove duplicates.

**Example**: Reverse Array In-place  
Reverse an array without extra space.

```javascript
function reverseArray(nums) {
    let left = 0, right = nums.length - 1;
    while (left < right) {
        [nums[left], nums[right]] = [nums[right], nums[left]];
        left++;
        right--;
    }
    return nums;
}
```

**Usage**:
```javascript
const nums = [1, 2, 3, 4, 5];
console.log(reverseArray(nums)); // [5, 4, 3, 2, 1]
```

**Complexity**:
- **Time**: O(n)
- **Space**: O(1)

## 8. Kadane’s Algorithm
**Description**: Finds the maximum subarray sum in **O(n)** time.

**Use Case**: Maximum subarray sum, profit intervals.

**Example**: Maximum Subarray Sum  
Find the maximum sum of a contiguous subarray.

```javascript
function maxSubarraySum(nums) {
    let maxSum = nums[0], currentSum = nums[0];
    for (let i = 1; i < nums.length; i++) {
        currentSum = Math.max(nums[i], currentSum + nums[i]);
        maxSum = Math.max(maxSum, currentSum);
    }
    return maxSum;
}
```

**Usage**:
```javascript
const nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4];
console.log(maxSubarraySum(nums)); // 6
```

**Complexity**:
- **Time**: O(n)
- **Space**: O(1)

## 9. Palindrome Checking
**Description**: Verifies if a string is a palindrome using two pointers.

**Use Case**: Validate palindromic strings.

**Example**: Valid Palindrome  
Check if a string is a palindrome, ignoring non-alphanumeric characters and case.

```javascript
function isPalindrome(s) {
    s = s.toLowerCase().replace(/[^a-z0-9]/g, '');
    let left = 0, right = s.length - 1;
    while (left < right) {
        if (s[left] !== s[right]) return false;
        left++;
        right--;
    }
    return true;
}
```

**Usage**:
```javascript
const s = "A man, a plan, a canal: Panama";
console.log(isPalindrome(s)); // true
```

**Complexity**:
- **Time**: O(n)
- **Space**: O(n)

## 10. String Hashing for Anagrams/Substrings
**Description**: Uses hash values for efficient string comparison.

**Use Case**: Group anagrams, find substrings.

**Example**: Group Anagrams  
Group anagrams from a list of strings.

```javascript
function groupAnagrams(strs) {
    const anagramMap = {};
    for (let str of strs) {
        const key = str.split('').sort().join('');
        anagramMap[key] = anagramMap[key] || [];
        anagramMap[key].push(str);
    }
    return Object.values(anagramMap);
}
```

**Usage**:
```javascript
const strs = ["eat", "tea", "tan", "ate", "nat", "bat"];
console.log(groupAnagrams(strs)); // [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]
```

**Complexity**:
- **Time**: O(n * k * log k) (n = strings, k = max string length)
- **Space**: O(n * k)
