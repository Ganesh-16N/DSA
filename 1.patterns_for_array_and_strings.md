1. Two Pointer Technique
Description: The Two Pointer Technique uses two pointers to traverse a data structure (e.g., array or string) efficiently, typically in O(n) time. It’s ideal for problems involving searching, partitioning, or comparing elements.
Use Case: Finding pairs with a specific sum, merging sorted arrays, or detecting cycles.
Example: Find Pair with Given Sum in Sorted Array
Given a sorted array and a target sum, find two numbers that add up to the target.


function findPairWithSum(arr, target) {
    let left = 0;
    let right = arr.length - 1;
    while (left < right) {
        const currentSum = arr[left] + arr[right];
        if (currentSum === target) {
            return [arr[left], arr[right]];
        } else if (currentSum < target) {
            left++;
        } else {
            right--;
        }
    }
    return [];
}

Usage:
const arr = [2, 7, 11, 15];
const target = 9;
console.log(findPairWithSum(arr, target)); // Output: [2, 7]

Explanation:

Initialize two pointers: left at the start and right at the end.
Compute the sum of elements at both pointers.
If the sum equals the target, return the pair.
If the sum is less than the target, increment left; if greater, decrement right.

Time Complexity: O(n) – Single pass through the array.Space Complexity: O(1) – Only uses two pointers.






2. Sliding Window
Description: The Sliding Window technique processes a subarray or substring by maintaining a dynamic window that expands or contracts based on conditions. It’s useful for contiguous subsequence problems.
Use Case: Finding the longest substring with unique characters, maximum/minimum sum of a subarray of size k, or substring matching.
Example: Maximum Sum of Subarray of Size K
Given an array and a number k, find the maximum sum of any contiguous subarray of size k.
function maxSumSubarray(arr, k) {
    if (k > arr.length) return 0;
    let windowSum = arr.slice(0, k).reduce((sum, num) => sum + num, 0);
    let maxSum = windowSum;
    for (let i = 0; i < arr.length - k; i++) {
        windowSum = windowSum - arr[i] + arr[i + k];
        maxSum = Math.max(maxSum, windowSum);
    }
    return maxSum;
}

Usage:
const arr = [1, 4, 2, 10, 2, 3, 1, 0, 20];
const k = 4;
console.log(maxSumSubarray(arr, k)); // Output: 24

Explanation:

Compute the sum of the first k elements.
Slide the window by subtracting the first element of the previous window and adding the next element.
Track the maximum sum encountered.

Time Complexity: O(n) – Initial window sum takes O(k), sliding takes O(n-k).Space Complexity: O(1) – Only stores window sum and max sum.





3. Hash Maps
Description: Hash Maps (using JavaScript’s Map or Object) provide O(1) average-time lookups, ideal for counting, grouping, or fast searches.
Use Case: Finding duplicates, grouping anagrams, or checking for subarrays with a given sum.
Example: Find All Anagrams in a String
Given a string s and a pattern p, find all starting indices of p’s anagrams in s.
function findAnagrams(s, p) {
    const result = [];
    const pCount = {};
    const sCount = {};

    // Initialize frequency map for p
    for (let char of p) {
        pCount[char] = (pCount[char] || 0) + 1;
    }

    // Initialize first window
    for (let i = 0; i < p.length; i++) {
        sCount[s[i]] = (sCount[s[i]] || 0) + 1;
    }

    // Compare initial window
    if (JSON.stringify(pCount) === JSON.stringify(sCount)) {
        result.push(0);
    }

    // Slide window
    for (let i = p.length; i < s.length; i++) {
        sCount[s[i - p.length]]--;
        if (sCount[s[i - p.length]] === 0) {
            delete sCount[s[i - p.length]];
        }
        sCount[s[i]] = (sCount[s[i]] || 0) + 1;
        if (JSON.stringify(pCount) === JSON.stringify(sCount)) {
            result.push(i - p.length + 1);
        }
    }
    return result;
}

Usage:
const s = "cbaebabacd";
const p = "abc";
console.log(findAnagrams(s, p)); // Output: [0, 6]

Explanation:

Create frequency maps for p and the initial window of s.
Slide the window, updating the frequency map by removing the leftmost character and adding the new one.
If frequency maps match, record the starting index.

Time Complexity: O(n) – Single pass through the string, with O(1) operations per character (assuming small character set).Space Complexity: O(k) – Where k is the size of the character set.





4. Sorting Tricks
Description: Sorting transforms an array into a monotonic order, enabling efficient searching or merging. It’s often a preprocessing step.
Use Case: Merging intervals, finding the kth largest element, or scheduling tasks.
Example: Merge Intervals
Given a collection of intervals, merge overlapping intervals.
function mergeIntervals(intervals) {
    if (!intervals.length) return [];
    intervals.sort((a, b) => a[0] - b[0]);
    const merged = [intervals[0]];
    for (let current of intervals.slice(1)) {
        if (current[0] <= merged[merged.length - 1][1]) {
            merged[merged.length - 1][1] = Math.max(merged[merged.length - 1][1], current[1]);
        } else {
            merged.push(current);
        }
    }
    return merged;
}

Usage:
const intervals = [[1, 3], [2, 6], [8, 10], [15, 18]];
console.log(mergeIntervals(intervals)); // Output: [[1, 6], [8, 10], [15, 18]]

Explanation:

Sort intervals by start time.
Iterate through sorted intervals, merging overlapping ones by updating the end time.
If no overlap, append the current interval.

Time Complexity: O(n log n) – Due to sorting.Space Complexity: O(n) – For the output array (sorting may use O(log n) stack space).




5. Binary Search on Arrays
Description: Binary Search finds a target in a sorted array in O(log n) time by dividing the search space in half.
Use Case: Searching for an element, finding boundaries, or optimization problems.
Example: Search in Rotated Sorted Array
Given a rotated sorted array and a target, find the target’s index.
function searchRotatedArray(nums, target) {
    let left = 0;
    let right = nums.length - 1;
    while (left <= right) {
        const mid = Math.floor((left + right) / 2);
        if (nums[mid] === target) return mid;
        if (nums[left] <= nums[mid]) {
            if (nums[left] <= target && target < nums[mid]) {
                right = mid - 1;
            } else {
                left = mid + 1;
            }
        } else {
            if (nums[mid] < target && target <= nums[right]) {
                left = mid + 1;
            } else {
                right = mid - 1;
            }
        }
    }
    return -1;
}

Usage:
const nums = [4, 5, 6, 7, 0, 1, 2];
const target = 0;
console.log(searchRotatedArray(nums, target)); // Output: 4

Explanation:

Use binary search, checking which half is sorted.
Determine if the target lies in the sorted half; adjust pointers accordingly.

Time Complexity: O(log n) – Binary search halves the search space each step.Space Complexity: O(1) – Only uses pointers.





6. Prefix Sum
Description: Prefix Sum precomputes cumulative sums to enable O(1) range sum queries after O(n) preprocessing.
Use Case: Range sum queries, finding subarrays with a given sum, or cumulative frequency.
Example: Range Sum Query
Given an array and a list of range queries, compute the sum of elements in each range.
function rangeSumQuery(nums, queries) {
    const prefix = [0];
    for (let i = 0; i < nums.length; i++) {
        prefix[i + 1] = prefix[i] + nums[i];
    }
    const result = [];
    for (let [left, right] of queries) {
        result.push(prefix[right + 1] - prefix[left]);
    }
    return result;
}

Usage:
const nums = [1, 2, 3, 4, 5];
const queries = [[1, 3], [2, 4]];
console.log(rangeSumQuery(nums, queries)); // Output: [9, 12]

Explanation:

Build a prefix sum array where prefix[i] is the sum of elements up to index i-1.
For a query [left, right], compute the sum as prefix[right + 1] - prefix[left].

Time Complexity: O(n) for preprocessing, O(1) per query.Space Complexity: O(n) for the prefix sum array.





7. In-place Modification
Description: In-place Modification manipulates the input array directly to minimize space usage, often using swaps or pointer-based updates.
Use Case: Reversing arrays, rotating arrays, or removing duplicates.
Example: Reverse Array In-place
Reverse an array without using extra space.
function reverseArray(nums) {
    let left = 0;
    let right = nums.length - 1;
    while (left < right) {
        [nums[left], nums[right]] = [nums[right], nums[left]];
        left++;
        right--;
    }
    return nums;
}

Usage:
const nums = [1, 2, 3, 4, 5];
console.log(reverseArray(nums)); // Output: [5, 4, 3, 2, 1]

Explanation:

Use two pointers to swap elements from the ends toward the center.
Continue until the pointers meet.

Time Complexity: O(n) – Single pass through half the array.Space Complexity: O(1) – Only uses pointers.





8. Kadane’s Algorithm
Description: Kadane’s Algorithm finds the maximum sum of a contiguous subarray in O(n) time by maintaining a running sum.
Use Case: Maximum subarray sum, finding maximum profit intervals, or contiguous sequence problems.
Example: Maximum Subarray Sum
Given an array, find the maximum sum of any contiguous subarray.
function maxSubarraySum(nums) {
    let maxSum = nums[0];
    let currentSum = nums[0];
    for (let i = 1; i < nums.length; i++) {
        currentSum = Math.max(nums[i], currentSum + nums[i]);
        maxSum = Math.max(maxSum, currentSum);
    }
    return maxSum;
}

Usage:
const nums = [-2, 1, -3, 4, -1, 2, 1, -5, 4];
console.log(maxSubarraySum(nums)); // Output: 6

Explanation:

Track the maximum sum ending at the current position (currentSum).
Update currentSum by either starting a new subarray or extending the existing one.
Track the global maximum (maxSum).

Time Complexity: O(n) – Single pass through the array.Space Complexity: O(1) – Only uses two variables.






9. Palindrome Checking
Description: Palindrome Checking verifies if a string reads the same forward and backward, often using two pointers.
Use Case: Validating palindromic strings, checking palindromic subsequences, or string manipulation.
Example: Valid Palindrome
Given a string, determine if it’s a palindrome, ignoring non-alphanumeric characters and case.
function isPalindrome(s) {
    s = s.toLowerCase().replace(/[^a-z0-9]/g, '');
    let left = 0;
    let right = s.length - 1;
    while (left < right) {
        if (s[left] !== s[right]) return false;
        left++;
        right--;
    }
    return true;
}

Usage:
const s = "A man, a plan, a canal: Panama";
console.log(isPalindrome(s)); // Output: true

Explanation:

Clean the string by removing non-alphanumeric characters and converting to lowercase.
Use two pointers to compare characters from both ends.
If any mismatch is found, return false; otherwise, return true.

Time Complexity: O(n) – Single pass for cleaning and checking.Space Complexity: O(n) – For the cleaned string.






10. String Hashing for Anagram/Substring Problems
Description: String Hashing assigns a hash value to strings (e.g., sorted string or frequency map) for efficient comparison, often used for anagrams or substring matching.
Use Case: Grouping anagrams, finding repeated substrings, or substring matching.
Example: Group Anagrams
Given a list of strings, group all anagrams together.
function groupAnagrams(strs) {
    const anagramMap = {};
    for (let str of strs) {
        const key = str.split('').sort().join('');
        if (!anagramMap[key]) anagramMap[key] = [];
        anagramMap[key].push(str);
    }
    return Object.values(anagramMap);
}

Usage:
const strs = ["eat", "tea", "tan", "ate", "nat", "bat"];
console.log(groupAnagrams(strs)); // Output: [["eat", "tea", "ate"], ["tan", "nat"], ["bat"]]

Explanation:

Sort each string to create a hash key (anagrams have the same sorted string).
Group strings by their sorted key in a hash map.
Return the grouped lists.

Time Complexity: O(n * k * log k) – Where n is the number of strings, k is the maximum string length (due to sorting).Space Complexity: O(n * k) – For the hash map and output.
