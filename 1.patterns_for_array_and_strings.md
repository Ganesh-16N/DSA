## 1. Two Pointer Technique 🕹️

**Description**: Uses two pointers to traverse a data structure (e.g., array or string) in **O(n)** time. Ideal for searching, partitioning, or comparing elements.

**Use Case**: Finding pairs with a specific sum, merging sorted arrays, detecting cycles.

**Example**: Find Pair with Given Sum in Sorted Array  
Find two numbers in a sorted array that add up to a target sum.

```javascript
function findPairWithSum(arr, target) {
    let left = 0;
    let right = arr.length - 1;
    while (left < right) {
        const currentSum = arr[left] + arr[right];
        if (currentSum === target) {
            return [arr[left], arr[right]];
        } else if (currentSum < target) {
            left++;
        } else {
            right--;
        }
    }
    return [];
}
```

**Usage**:
```javascript
const arr = [2, 7, 11, 15];
const target = 9;
console.log(findPairWithSum(arr, target)); // Output: [2, 7]
```

**Explanation**:
- Initialize two pointers: `left` at start and `right` at end
- Compute sum of elements at both pointers
- If sum equals target, return the pair
- If sum is less than target, increment `left`; if greater, decrement `right`

**Complexity**:
- ⏱️ Time: O(n) – Single pass through array
- 💾 Space: O(1) – Only uses two pointers

## 2. Sliding Window 🪟

**Description**: Maintains a dynamic window that expands/contracts to process contiguous subsequences efficiently.

**Use Case**: Longest substring with unique characters, maximum sum of subarray of size k.

**Example**: Maximum Sum of Subarray of Size K

```javascript
function maxSumSubarray(arr, k) {
    if (k > arr.length) return 0;
    let windowSum = arr.slice(0, k).reduce((sum, num) => sum + num, 0);
    let maxSum = windowSum;
    for (let i = 0; i < arr.length - k; i++) {
        windowSum = windowSum - arr[i] + arr[i + k];
        maxSum = Math.max(maxSum, windowSum);
    }
    return maxSum;
}
```

**Usage**:
```javascript
const arr = [1, 4, 2, 10, 2, 3, 1, 0, 20];
const k = 4;
console.log(maxSumSubarray(arr, k)); // Output: 24
```

**Explanation**:
- Compute sum of first k elements
- Slide window by subtracting leftmost element and adding next element
- Track maximum sum encountered

**Complexity**:
- ⏱️ Time: O(n)
- 💾 Space: O(1)

## 3. Hash Maps 🗺️

**Description**: Provides O(1) average-time lookups using JavaScript's Map or Object.

**Use Case**: Finding duplicates, grouping anagrams, checking subarrays with given sum.

**Example**: Find All Anagrams in a String

```javascript
function findAnagrams(s, p) {
    const result = [];
    const pCount = {};
    const sCount = {};

    // Initialize frequency map for p
    for (let char of p) {
        pCount[char] = (pCount[char] || 0) + 1;
    }

    // Initialize first window
    for (let i = 0; i < p.length; i++) {
        sCount[s[i]] = (sCount[s[i]] || 0) + 1;
    }

    // Compare initial window
    if (JSON.stringify(pCount) === JSON.stringify(sCount)) {
        result.push(0);
    }

    // Slide window
    for (let i = p.length; i < s.length; i++) {
        sCount[s[i - p.length]]--;
        if (sCount[s[i - p.length]] === 0) {
            delete sCount[s[i - p.length]];
        }
        sCount[s[i]] = (sCount[s[i]] || 0) + 1;
        if (JSON.stringify(pCount) === JSON.stringify(sCount)) {
            result.push(i - p.length + 1);
        }
    }
    return result;
}
```

**Usage**:
```javascript
const s = "cbaebabacd";
const p = "abc";
console.log(findAnagrams(s, p)); // Output: [0, 6]
```

**Complexity**:
- ⏱️ Time: O(n)
- 💾 Space: O(k) (character set size)
